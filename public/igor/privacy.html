Igor: Privacy Policy

Last updated: November 12, 2026

Igor is a Discord bot for gaming communities. This page explains what it stores, why, and how to remove it.

What Igor stores

  • Server settings: the channels and options set with /config.
  • WoW characters a server tracks: name, game version and region, the latest public level and item level from Blizzard's API, and who added it.
  • Characters you claim with /wow claim: which characters are yours, which is your main, and whether you verified them. Several people can claim the same character until one of them verifies it. Your claims show only in servers you approve: where you claimed, tracked or looked up the character yourself, or where you said yes when Igor asked you by direct message. There they appear in /wow list, /wow mine and next to the character's posts. /wow here changes this for one server, and /wow sharing new_servers:everywhere skips the asking.
  • Live WoW events, for players who use the DOINK add-on with Igor: the character name and what happened (a level, loot, a death, a boss kill and similar), with the time.
  • Daily-game results, only in a channel a server picks as its daily-games channel: Igor reads the messages there to find shared game results (Wordle, Anno, Clues by Sam and similar, including Anno's screenshot card, which it reads with text recognition). It keeps what it read from each message (the game and the score) for 30 days, to post each day's head-to-head and the week's game links. It doesn't keep the messages themselves.
  • Auto-responders a server sets up with /autoresponse: the keyword, the reply and reactions, and who created it.
  • Activity for weekly stats, only if the server has the feature on and you haven't opted out:
    • which game Discord shows you playing, with start and end times;
    • which voice channel you were in, with join and leave times.

Igor reads messages only for three things: the DOINK posts sent to Igor's own webhook; the daily-games channel a server chose; and, in servers with auto-responders, each message is checked against those keywords at the moment it's sent and then forgotten.

How long

  • Activity and live WoW events: deleted after 90 days.
  • Daily-game results: deleted after 30 days.
  • Blizzard data: refreshed or deleted within 30 days, as Blizzard's API terms require.
  • Backups: nightly copies of the database are kept for 7 days.
  • Server removal: removing Igor from a server deletes that server's data.

Your choices

  • /privacy tracking:false stops recording your games and voice time in every server.
  • /forget-me deletes your activity, the characters you added or claimed, and your settings, everywhere. Copies in backups age out within 7 days.

Sharing

Igor's data is never sold or shared. The only outside service Igor sends requests to is Blizzard's API (character lookups), and those requests contain nothing about you. Screenshots in a daily-games channel are downloaded from Discord itself and read on Igor's own server; they aren't sent anywhere else.
